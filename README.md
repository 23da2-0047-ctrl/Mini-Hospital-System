# Mini Hospital Emergency Management System

A Java-based Hospital Management System developed for **CIT300 - Data Structures and Algorithms**. The system simulates patient registration, emergency queue processing, treatment history tracking, and patient visit records using optimal data structures.

## 🚀 Data Structures Implemented
1. **Patient Records (Binary Search Tree - BST):** Efficient insertion, searching, deletion, and in-order traversal using Patient ID as the key.
2. **Emergency Patient Queue (Queue - FIFO):** First-In, First-Out queue for managing patients arriving at the emergency unit.
3. **Treatment History (Stack - LIFO):** Last-In, First-Out stack to maintain completed treatment logs.
4. **Patient Visit History (Singly Linked List):** Dynamic linked list attached to each patient for tracking past hospital visits.
